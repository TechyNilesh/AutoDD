\begin{abstract}
Concept drift, the change in the distribution of streaming data over time, significantly impacts the performance of machine learning models. While numerous drift detection methods have been proposed, selecting and configuring the most suitable detector for a specific data stream remains a challenging task. Existing AutoML frameworks for streaming data automate model selection but rely on fixed drift detection strategies, leaving a critical gap in automation. This paper introduces \textbf{AutoDD} (\textbf{A}utomated \textbf{D}rift \textbf{D}etector), a novel framework that jointly automates detector selection and hyperparameter configuration using a hierarchical learning approach. AutoDD extracts comprehensive online meta-features and employs a two-level hierarchical selection algorithm to adaptively choose both the detector and its configuration. Theoretical analysis provides sublinear regret bounds ensuring convergence to optimal performance. Comprehensive experiments on synthetic and real-world datasets demonstrate that AutoDD consistently outperforms state-of-the-art detectors while maintaining computational efficiency.
\end{abstract}

\section{Introduction}

Concept drift, where the statistical properties of streaming data evolve over time, poses a significant challenge in data stream mining \cite{Gama2014Survey}, incremental learning \cite{Losing2018IncrementalOnline}, and non-stationary learning \cite{Lu2019Learning}. As data distributions change, machine learning models experience degraded performance, necessitating timely detection and adaptation. This phenomenon manifests in various forms, including sudden (abrupt) drift, gradual drift, incremental drift, and recurring drift, as illustrated in Figure~\ref{fig:type_of_drift}. For instance, an electricity price prediction model may encounter sudden drift when market regulations change abruptly, experience gradual drift as consumer behavior shifts over seasons, or observe recurring drift driven by daily demand cycles~\cite{Lu2019Learning}.

\begin{figure}[!t]
    \centering
    \includegraphics[width=0.75\columnwidth]{images/type_of_drift_detection.png}
    \caption{Types of concept drifts.}
    \label{fig:type_of_drift}
\end{figure}

Over the past two decades, numerous drift detection methods have been developed to address this challenge, including error rate-based approaches such as DDM \cite{Gama2004DDM}, ADWIN \cite{Bifet2007ADWIN}, and ADDM \cite{Mayaki2022ADDM}, distribution-based methods like KSWIN \cite{Raab2020KSWIN}, uncertainty-based methods such as PUDD \cite{Lu2025PUDD}, and meta-learning techniques like Meta-ADD \cite{Yu2021MetaADD}. However, a fundamental challenge remains unresolved in systematically selecting and configuring the most appropriate drift detector for a given data stream.

Automated Machine Learning (AutoML) has revolutionized the field by addressing similar selection challenges in batch learning scenarios \cite{Hutter2019AutoML}. Recent advancements have extended AutoML to streaming data, enabling automatic selection and configuration of classifiers \cite{Celik2023OAML,Verma2024ASML}. However, these systems treat drift detection as a fixed component, requiring manual specification and leaving a critical gap in the automation framework.

To bridge this gap, we introduce \textbf{AutoDD} (\textbf{A}utomated \textbf{D}rift \textbf{D}etector). This modular framework automates drift detector selection and configuration using a hierarchical learning approach, compatible with any model or AutoML pipeline.

\begin{itemize}
\item We propose a two-level hierarchical selection algorithm using LinUCB \cite{Li2010LinUCB} and Thompson Sampling \cite{Agrawal2012Thompson} that adaptively selects detectors and their hyperparameters based on online meta-features.
\item We formalize detector selection with a theoretical analysis that provides sublinear regret bounds guaranteeing convergence to optimal selections.
\item Extensive evaluation demonstrates AutoDD outperforms state-of-the-art detectors while maintaining computational efficiency.
\end{itemize}

Section~\ref{sec:experiments} describes the experimental setup. Section~\ref{sec:results} presents the experimental results and analysis. %Section~\ref{sec:discussion} addresses key design decisions and limitations. 
Finally, Section~\ref{sec:conclusion} concludes the paper.

\section{Related Work}
\label{sec:related}

Drift detection methods can be broadly categorized into three paradigms. \textbf{Error rate-based methods} monitor fluctuations in classifier error rates, triggering alarms when changes are statistically significant. DDM \cite{Gama2004DDM} pioneered the warning-drift framework by monitoring prediction accuracy under binomial distribution assumptions, followed by EDDM \cite{BaenaGarcia2006EDDM} which focuses on distances between errors to detect gradual drift, HDDM \cite{FriasBlanco2015Hoeffding} which applies Hoeffding's inequality with exponentially weighted moving averages, and ADWIN \cite{Bifet2007ADWIN} which maintains adaptive sliding windows that automatically shrink when distribution changes are detected. Page-Hinkley \cite{Page1954Continuous} applies cumulative sum control charts to detect mean shifts in sequential data. Recent advances include MDDM \cite{Pesaranghader2017MDDM}, which uses McDiarmid's inequality for shorter detection delays with tighter concentration bounds, and ADDM \cite{Mayaki2022ADDM}, which models error rates as SETAR time series \cite{Tsay1989TestingAM} to achieve lower false alarm rates. \textbf{Distribution-based methods} compare data distributions across windows by quantifying dissimilarity between new and historical data distributions \cite{Kifer2004ChangeDetection}, including approaches based on information theory \cite{Dasu2006InformationTheoretic}, competence models \cite{Lu2014CompetenceModels}, and the Kolmogorov-Smirnov test (KSWIN) \cite{Raab2020KSWIN} which detects changes in univariate feature distributions. \textbf{Uncertainty and learning-based methods} address limitations of error-rate monitoring: PUDD \cite{Lu2025PUDD} leverages prediction confidence for earlier detection by monitoring changes in prediction uncertainty distributions, while Meta-ADD \cite{Yu2021MetaADD} employs prototypical networks to classify drift types via meta-learning on diverse drift scenarios.

Recent developments in automated algorithm selection and hyperparameter optimization (CASH) \cite{Hutter2019AutoML} have been extended to streaming scenarios~\cite{kulbach2022evolution}. 
However, all existing streaming AutoML systems assume a pre-selected drift detector, requiring manual specification and leaving a critical gap in the automation framework. Despite advances in both drift detection and streaming AutoML, drift detector selection remains manual. Our work fills this gap by extending AutoML to automatic drift detector selection and configuration.


\section{Automated Drift Detector}
\label{sec:method}

AutoDD employs an adaptive, closed-loop architecture to dynamically select and configure drift detectors. As shown in Figure~\ref{fig:framework}, this architecture operates through several key steps. First, the system initializes the detector portfolio with standard hyperparameters and sets up the learning parameters. During online operation, meta-features characterizing stream velocity, stationarity, and temporal patterns are continuously extracted from the incoming data stream. These meta-features serve as context for the LinUCB agent, which selects the most appropriate detector from the portfolio. Thompson Sampling then configures the selected detector's hyperparameters for optimal performance. The configured detector monitors the stream and triggers model adaptation upon detecting drift. Finally, performance feedback is computed based on detection outcomes, which updates both the LinUCB and Thompson Sampling components to refine future selections. This adaptive learning cycle enables AutoDD to continuously improve its detector selections over time.

\subsection{Hierarchical Learning Approach}

AutoDD uses a two-level hierarchical selection strategy that jointly optimizes detector choice and hyperparameter configuration while maintaining computational efficiency. This approach avoids the combinatorial explosion of $K \times C$ configurations by decomposing the problem into hierarchical decisions.

\textbf{Level 1 - Detector Selection via LinUCB:} We formulate detector selection as a contextual multi-armed bandit problem where context is $\boldsymbol{\phi}_t$ (meta-features), arms are $K$ detectors, and reward is detection performance. LinUCB \cite{Li2010LinUCB} assumes linear reward:
\begin{equation}
r_{i,t} = \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_i + \epsilon_t
\end{equation}
where $\boldsymbol{\theta}_i \in \mathbb{R}^m$ is the unknown parameter vector for detector $i$, with $m$ being the meta-feature dimensionality. The algorithm selects the detector with the highest upper confidence bound:
\begin{equation}
\resizebox{0.9\columnwidth}{!}{$
i_t = \arg\max_{i \in [K]} \left( \boldsymbol{\phi}_t^\top \hat{\boldsymbol{\theta}}_i + \alpha_{\text{ucb}} \sqrt{\boldsymbol{\phi}_t^\top \mathbf{A}_i^{-1} \boldsymbol{\phi}_t} \right)
$}
\end{equation}
where $\hat{\boldsymbol{\theta}}_i = \mathbf{A}_i^{-1} \mathbf{b}_i$ is the ridge regression estimate. Here, $\mathbf{A}_i = \lambda_{\text{reg}}\mathbf{I} + \sum_{s:i_s=i} \boldsymbol{\phi}_s \boldsymbol{\phi}_s^\top \in \mathbb{R}^{m \times m}$ is the regularized design matrix with regularization parameter $\lambda_{\text{reg}} > 0$, and $\mathbf{b}_i = \sum_{s:i_s=i} r_s \boldsymbol{\phi}_s \in \mathbb{R}^m$ is the cumulative reward-weighted context vector for detector $i$. The parameter $\alpha_{\text{ucb}} > 0$ controls exploration-exploitation balance.

\textbf{Level 2 - Hyperparameter Selection via Thompson Sampling:} Given the selected detector $D_{i_t}$, we adaptively configure its hyperparameters using Thompson Sampling \cite{Agrawal2012Thompson}. For each configuration $c \in [C] = \{1, \ldots, C\}$ of detector $i$, we maintain Beta distribution parameters $(a_{i,c}, b_{i,c})$ initialized to $(1, 1)$. At each window, we sample:
\begin{equation}
\label{eq:ts_sample}
\psi_{i_t,c} \sim \text{Beta}(a_{i_t,c}, b_{i_t,c}) \quad \forall c \in [C]
\end{equation}
and select configuration:
\begin{equation}
\label{eq:ts_select}
c_t = \arg\max_c \psi_{i_t,c}
\end{equation}

After observing reward $r_t$, we update:
\begin{align}
\label{eq:ts_update}
a_{i_t,c_t} &\gets a_{i_t,c_t} + \tilde{r}_t \\
b_{i_t,c_t} &\gets b_{i_t,c_t} + (1 - \tilde{r}_t)
\end{align}
where $\tilde{r}_t = (r_t + 1)/2$ normalizes the reward to $[0,1]$. %This cascading approach provides tractability (only $K$ arms at Level 1), specialization (each detector's hyperparameters tuned independently), and fast adaptation (Thompson Sampling quickly identifies effective configurations).

\subsection{Evaluation and Adaptation}

Evaluating detector performance without ground-truth drift labels is challenging. Following standard practice, we use model accuracy drop as a proxy metric. The reward at time $t$ is:
\begin{equation}
\label{eq:reward}
r_t = \begin{cases}
0.5 + \min(\Delta a_t \cdot 2, 0.5) & d_t=1, \Delta a_t > \tau_{\text{sig}} \\
-0.3 & d_t=1, \Delta a_t \leq \tau_{\text{sig}} \\
-0.5 - \min(\Delta a_t, 0.5) & d_t=0, \Delta a_t > \tau_{\text{sig}} \\
0.1 & d_t=0, \Delta a_t \leq \tau_{\text{sig}}
\end{cases}
\end{equation}
where $d_t \in \{0,1\}$ indicates drift detection at time $t$, $\Delta a_t = a_{t-w} - a_t$ is the accuracy drop between consecutive windows, and $\tau_{\text{sig}} = 0.05$ is the significance threshold. The reward function penalizes both false positives and false negatives while rewarding correct drift detections and stable periods. We note that an accuracy-based proxy couples detector quality with the downstream learner, label noise, and the evaluation window. Two design choices limit the resulting variance: the drop $\Delta a_t$ is measured over a window of $w$ instances rather than per-instance, smoothing transient noise, and the threshold $\tau_{\text{sig}}$ suppresses rewards from sub-significant fluctuations so that noise-driven dips do not reinforce spurious detections. Because the reward enters the bandit update only as a bounded scalar in $[-1,1]$, occasional misattributed rewards perturb the posteriors gradually rather than abruptly, and the sublinear regret of Section~\ref{sec:method} continues to hold provided the proxy is, in expectation, monotone in true detection quality.

Upon drift detection, the model undergoes a complete reset. Let $\mathcal{M}_t$ denote the model state at time $t$. When drift is detected ($d_t = 1$), we perform:
\begin{equation}
\mathcal{M}_t \gets \mathcal{M}_0
\end{equation}
where $\mathcal{M}_0$ represents the initial untrained state. The model then resumes incremental learning from subsequent instances:
\begin{equation}
\mathcal{M}_{t+s} \gets \text{Update}(\mathcal{M}_{t+s-1}, (\mathbf{x}_{t+s}, y_{t+s})) \quad \forall s > 0
\end{equation}

The complete procedure is formalized in Algorithm~\ref{alg:autodd}.

\begin{algorithm}[!t]
\caption{AutoDD Algorithm}
\label{alg:autodd}
\textbf{Input:} Stream $\mathcal{S}$, Portfolio $\mathcal{D}$, Window $w$\\
\textbf{Parameter:} Exploration $\alpha_{\text{ucb}}$, Regularization $\lambda_{\text{reg}}$, Configs per detector $C$\\
\textbf{Output:} Drift signals $\{d_t\}_{t=1}^\infty$
\begin{algorithmic}[1]
\STATE Initialize $\mathbf{A}_i \gets \lambda_{\text{reg}}\mathbf{I}_m$, $\mathbf{b}_i \gets \mathbf{0}$ for all $i \in [K]$
\STATE Initialize $a_{i,c} \gets 1$, $b_{i,c} \gets 1$ for all $i \in [K], c \in [C]$
\STATE Initialize model $\mathcal{M}_0$, sliding window $W \gets \emptyset$
\FOR{each instance $(\mathbf{x}_t, y_t) \in \mathcal{S}$}
    \STATE $W \gets W \cup \{(\mathbf{x}_t, y_t)\}$
    \IF{$|W| = w$}
        \STATE $\boldsymbol{\phi}_t \gets \textsc{Extract}(W)$ \COMMENT{Extract meta-features}
        %\STATE \textit{// Level 1: Detector Selection (LinUCB)}
        \FOR{$i = 1$ to $K$}
            \STATE $\text{UCB}_i \gets \boldsymbol{\phi}_t^\top \mathbf{A}_i^{-1} \mathbf{b}_i + \alpha_{\text{ucb}} \sqrt{\boldsymbol{\phi}_t^\top \mathbf{A}_i^{-1} \boldsymbol{\phi}_t}$
        \ENDFOR
        \STATE $i_t \gets \arg\max_i \text{UCB}_i$ \COMMENT{Select detector}
        %\STATE \textit{// Level 2: Hyperparameter Selection (Thompson Sampling)}
        \FOR{$c = 1$ to $C$}
            \STATE Sample $\psi_c \sim \text{Beta}(a_{i_t,c}, b_{i_t,c})$
        \ENDFOR
        \STATE $c_t \gets \arg\max_c \psi_c$ \COMMENT{Select configuration}
        \STATE $d_t \gets D_{i_t}(\boldsymbol{\eta}_{i_t,c_t}).\textsc{Detect}(W)$
        \IF{$d_t = 1$}
            \STATE $\mathcal{M}_t \gets \mathcal{M}_0$ %\textit{// Reset model to initial state}
        \ENDIF
        \STATE \COMMENT{Compute reward $r_t$ using Eq.~\eqref{eq:reward}}
        %\STATE \textit{// Update Level 1 (LinUCB)}
        \STATE $\mathbf{A}_{i_t} \gets \mathbf{A}_{i_t} + \boldsymbol{\phi}_t \boldsymbol{\phi}_t^\top$; $\mathbf{b}_{i_t} \gets \mathbf{b}_{i_t} + r_t \boldsymbol{\phi}_t$
        %\STATE \textit{// Update Level 2 (Thompson Sampling)}
        \STATE $\tilde{r}_t \gets (r_t + 1)/2$
        \STATE $a_{i_t,c_t} \gets a_{i_t,c_t} + \tilde{r}_t$; $b_{i_t,c_t} \gets b_{i_t,c_t} + (1-\tilde{r}_t)$
        \STATE $W \gets \emptyset$
    \ENDIF
\ENDFOR
\end{algorithmic}
\end{algorithm}

\subsection{Computational Complexity}
AutoDD has per-window complexity of $O(wd + Km^2)$, where $w$ is the AutoDD window size, $d$ is the input feature dimensionality, $K$ is the number of detectors, and $m=15$ is the meta-feature count. The dominant costs are meta-feature extraction ($O(wd)$) and LinUCB matrix operations ($O(Km^2)$). Space complexity is $O(Km^2 + wd)$ for storing $K$ covariance matrices of size $m \times m$ and the sliding window buffer.

\subsection{Theoretical Analysis}

We formalize the optimization objective as a streaming detector selection problem and provide regret guarantees for the hierarchical learning approach. Our analysis focuses on the selection mechanism, demonstrating that AutoDD effectively converges to the optimal drift detector and hyperparameter configuration from the available portfolio.\footnote{Complete proofs are provided in Appendix~\ref{appendix:proofs}.}

\textbf{Problem Formulation.} A data stream $\mathcal{S} = \{(\mathbf{x}_t, y_t)\}_{t=1}^{\infty}$ exhibits concept drift when distributions change over time:
\begin{equation}
\exists t, t' : P_t(\mathbf{x}, y) \neq P_{t'}(\mathbf{x}, y)
\end{equation}

Given a detector portfolio $\mathcal{D} = \{D_1, \ldots, D_K\}$ where each $D_i$ has configuration space $\mathcal{H}_i$, AutoDD addresses the streaming detector selection and configuration problem. Inspired by the CASH formulation \cite{Hutter2019AutoML}, we jointly optimize the detector choice and its hyperparameters:
\begin{equation}
\resizebox{0.95\columnwidth}{!}{$
(D^*_t, \boldsymbol{\eta}^*_t) = \arg\max_{D_i \in \mathcal{D}, \boldsymbol{\eta} \in \mathcal{H}_i} \mathbb{E}[\mathcal{M}(D_i(\boldsymbol{\eta}), \mathcal{S}_t) \mid \boldsymbol{\phi}_t]
$}
\end{equation}
where $\boldsymbol{\phi}_t$ is the stream context, $\mathcal{S}_t$ denotes the stream segment at time $t$, $\mathbb{E}[\cdot]$ is the expectation operator, and $\mathcal{M}$ denotes the downstream model performance.

\textbf{Assumptions.} We adopt three standard assumptions from the contextual bandit literature \cite{Abbasi2011Improved,Lattimore2020Bandit}:
\begin{itemize}
\item \textbf{(A1) Bounded features:} $\|\boldsymbol{\phi}_t\|_2 \leq L$ for all $t$, satisfied by $[0,1]$ normalization with $L=\sqrt{m}$.
\item \textbf{(A2) Linear reward:} For each detector $i$, there exists $\boldsymbol{\theta}_i^* \in \mathbb{R}^m$ with $\|\boldsymbol{\theta}_i^*\|_2 \leq S$ such that $\mathbb{E}[r_{i,t} \mid \boldsymbol{\phi}_t] = \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_i^*$, where $S > 0$ is a constant upper bound on the parameter norms.
\item \textbf{(A3) Sub-Gaussian noise:} Reward noise is $\sigma_{\text{noise}}$-sub-Gaussian, satisfied with $\sigma_{\text{noise}} = 1$ for bounded rewards in $[-1,1]$.
\end{itemize}

The following result establishes that LinUCB learns optimal detector selection with sublinearly diminishing regret.

\textbf{Theorem 1 (Level 1 Regret).} Under assumptions A1--A3, with exploration parameter $\alpha_{\text{ucb}} = \sigma_{\text{noise}}\sqrt{m \log(KT/\delta_{\text{conf}})} + S$ where $T$ is the time horizon and $\delta_{\text{conf}} \in (0,1)$ is the confidence parameter, LinUCB detector selection achieves with probability at least $1 - \delta_{\text{conf}}$:
\begin{equation}
\resizebox{0.95\columnwidth}{!}{$
R_1(T) = \sum_{t=1}^{T} \left( \max_{i} \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_i^* - \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_{i_t}^* \right) = O(\sqrt{mT \log T})
$}
\end{equation}

\textit{Proof.} The proof follows directly from Theorem 2 of \cite{Abbasi2011Improved}. By the self-normalized martingale inequality (Theorem 1, \cite{Abbasi2011Improved}), the true parameter $\boldsymbol{\theta}_i^*$ lies within the confidence ellipsoid $\mathcal{C}_{i,t} = \{\boldsymbol{\theta}: \|\boldsymbol{\theta} - \hat{\boldsymbol{\theta}}_i\|_{\mathbf{A}_i} \leq \alpha_{\text{ucb}}\}$ with probability $1-\delta_{\text{conf}}$. Under this event, UCB selection ensures $\boldsymbol{\phi}_t^\top \boldsymbol{\theta}_{i_t}^* \geq \max_i \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_i^* - 2\alpha_{\text{ucb}}\|\boldsymbol{\phi}_t\|_{\mathbf{A}_{i_t}^{-1}}$. Summing over all rounds and applying the elliptical potential lemma \cite{Dani2008Stochastic} yields $\sum_{t=1}^T \|\boldsymbol{\phi}_t\|_{\mathbf{A}_{i_t}^{-1}} \leq \sqrt{2mT\log(1+TL^2/m)}$, establishing the stated bound. \hfill $\square$

Thompson Sampling subsequently balances exploration and exploitation for hyperparameter configuration.

\textbf{Theorem 2 (Level 2 Regret).} For Thompson Sampling on $C$ configurations per detector, with $N_i(T)$ denoting the number of times detector $i \in [K]$ is selected over $T$ rounds, the cumulative regret satisfies:
\begin{equation}
R_2(T) = \sum_{i=1}^{K} O(\sqrt{C \cdot N_i(T) \log N_i(T)})
\end{equation}

\textit{Proof.} For each detector $i \in [K]$, conditioned on detector $i$ being selected, hyperparameter selection reduces to a $C$-armed bandit with bounded rewards. We normalize $r_t \in [-1,1]$ to $\tilde{r}_t = (r_t+1)/2 \in [0,1]$ and maintain Beta posteriors updated with $\tilde{r}_t$. By Theorem 1 of \cite{Agrawal2013Further}, Thompson Sampling achieves expected regret $O(\sqrt{CN_i(T)\log N_i(T)})$ over $N_i(T)$ rounds. Since $\sum_i N_i(T) = T$, summing across all detectors yields the stated bound. \hfill $\square$

The combined regret remains sublinear, ensuring that AutoDD's average per-round suboptimality vanishes over time.

\textbf{Corollary (Combined Regret).} Let $(i^*, c^*)$ denote the optimal detector-configuration pair. The total regret decomposes as $R(T) = R_1(T) + R_2(T)$, where $R_1(T)$ captures suboptimality from detector selection and $R_2(T)$ from configuration selection. The combined bound is:
\begin{equation}
R(T) = O(\sqrt{mT \log T} + \sqrt{CKT \log T})
\end{equation}

\textit{Proof.} By the Cauchy-Schwarz inequality, $\sum_i \sqrt{N_i(T)} \leq \sqrt{K \sum_i N_i(T)} = \sqrt{KT}$. Thus $R_2(T) = O(\sqrt{CKT\log T})$, and combining with $R_1(T)$ yields the result. \hfill $\square$

This sublinear regret bound guarantees convergence to optimal detector-configuration pairs:
\begin{equation}
\lim_{T \to \infty} \frac{R(T)}{T} = 0
\end{equation}
Empirical validation of this convergence is provided in Table~\ref{tab:conv_main}, where AutoDD's selection accuracy improves from 69.4\% in the first quarter of the stream to 93.1\% by stream end, confirming that the linear reward approximation is well-supported in practice.

\section{Experiments}
\label{sec:experiments}

We evaluate AutoDD on ten benchmark datasets comprising five synthetic and five real-world streams, with characteristics detailed in Table~\ref{tab:datasets}. To isolate drift detection performance from model selection effects, all methods use two fixed base models: GaussianNB and Hoeffding Adaptive Tree (HAT)~\cite{domingos2000mining}. These two learners represent fundamentally different model families (probabilistic and tree-based) and are the standard benchmark base learners used in the data stream mining literature~\cite{Bifet2010MOA,Barros2018}. We compare AutoDD against twelve baselines: a no-detector baseline, seven portfolio detectors including ADWIN, DDM, EDDM, HDDM-A, HDDM-W, Page-Hinkley, KSWIN, and four state-of-the-art methods including MDDM \cite{Pesaranghader2017MDDM}, ADDM \cite{Mayaki2022ADDM}, PUDD \cite{Lu2025PUDD}, and Meta-ADD \cite{Yu2021MetaADD}. All detectors use recommended hyperparameter settings from the literature.

We measure prequential accuracy as the percentage of correct predictions using test-then-train evaluation~\cite{Bifet2010MOA}. For synthetic datasets with known drift points, we report F1-score computed by matching detected drifts to ground truth using a tolerance window of $\tau_{\text{tol}}=100$ instances following standard practice \cite{Bifet2007ADWIN}. For real-world datasets, we report the number of detected drifts (DN). These metrics are complementary by design: prequential accuracy captures the downstream task impact of a detector's adaptation decisions, whereas the drift-detection F1-score scores precision and recall against ground-truth drift points and thus credits timely, correct detections while penalizing both missed drifts and spurious alarms that accuracy alone would not separate. On real-world streams the drift points are unknown, so F1 cannot be computed and we instead report DN alongside accuracy; following the benchmarking guidance of Souza et al.~\cite{Souza2020Benchmark}, we interpret DN relative to the consensus detection range across methods rather than as an absolute target, treating values far above or below this range as over- and under-detection respectively. AutoDD uses all 15 meta-features with window size $w=100$, exploration parameter $\alpha_{\text{ucb}}=1.0$, regularization parameter $\lambda_{\text{reg}}=1.0$, and $C=5$ hyperparameter configurations per detector. Results are averaged over 10 runs with random seeds uniformly sampled from the range [1, 100]. Implementation uses Python with River~\cite{Montiel2021River} on a MacBook Pro with Apple M2 Pro and 16GB RAM.\footnote{Code: https://anonymous.4open.science/r/AutoDD-BCCF}

\textbf{Discussion and Limitations:} We highlight several boundaries of the current design. First, AutoDD automates detector and hyperparameter selection but not the sliding-window size $w$, which the sensitivity analysis shows to be the most influential setting; $w=100$ is robust across our benchmarks, yet selecting it for an unseen stream remains a manual step that an outer adaptive loop could close. Second, the reward is an accuracy-based proxy and therefore entangles detector quality with the downstream learner; we mitigate this through window-level smoothing and the significance threshold (Section~\ref{sec:method}), but a fully label-free reward is an open problem. Third, to isolate detection from model selection we fix the base learner to GaussianNB and HAT---two standard but limited families---and adapt via full model reset; richer learners and softer adaptation strategies (warm-starting, selective parameter resets, replay, ensemble updating) are left to future work. Finally, AutoDD targets tabular data streams, the prevalent setting in the drift-detection literature; non-tabular modalities such as image, audio, and text are outside the scope of this work. Within the tabular setting, the portfolio covers the principal detector families through their strongest and most recent representatives: the statistical two-sample test family such as IKS~\cite{dosReis2016IKS} and WRS~\cite{Barros2018} is represented by the newer KSWIN, HDDM, and ADWIN. Because AutoDD is detector-agnostic, incorporating additional tabular detectors is a natural extension of the framework rather than a change to its selection mechanism.

\section{Conclusion and Future Work}
\label{sec:conclusion}

We propose AutoDD, a novel framework that automatically selects and configures drift detectors for data streams. The framework extracts comprehensive meta-features and employs a two-level hierarchical selection strategy using LinUCB for detector selection and Thompson Sampling for hyperparameter configuration. Theoretical analysis provides sublinear regret bounds guaranteeing convergence to optimal detector-configuration pairs. Extensive experimental results on synthetic and real-world datasets demonstrate that AutoDD achieves considerable improvements over fixed detector baselines and state-of-the-art methods while requiring no expert intervention. Beyond the limitation-driven extensions discussed in Section~\ref{sec:results}, a further direction is multi-objective selection that jointly balances predictive accuracy, detection latency, and computational efficiency.

\section{Theoretical Proofs}\label{appendix:proofs}

This section provides detailed proofs for the theoretical results presented in the main paper.

\subsection{Preliminaries and Notation}

Let $\mathcal{S} = \{(\mathbf{x}_t, y_t)\}_{t=1}^{\infty}$ denote the data stream, $\mathcal{D} = \{D_1, \ldots, D_K\}$ with $K=7$ the detector portfolio, and $\boldsymbol{\phi}_t \in \mathbb{R}^m$ the meta-feature vector at time $t$ with $m=15$. For LinUCB, we maintain for each detector $i$: the design matrix $\mathbf{A}_i = \lambda_{\text{reg}}\mathbf{I} + \sum_{s:i_s=i} \boldsymbol{\phi}_s \boldsymbol{\phi}_s^\top$ and the response vector $\mathbf{b}_i = \sum_{s:i_s=i} r_s \boldsymbol{\phi}_s$. The ridge regression estimate is $\hat{\boldsymbol{\theta}}_i = \mathbf{A}_i^{-1} \mathbf{b}_i$.

\subsection{Proof of Theorem 1 (Level 1 Regret)}

\textbf{Theorem 1.} \textit{Under assumptions A1--A3, with exploration parameter $\alpha_{\text{ucb}} = \sigma_{\text{noise}}\sqrt{m \log(KT/\delta_{\text{conf}})} + S$, LinUCB detector selection achieves with probability at least $1 - \delta_{\text{conf}}$:}
\begin{equation}
R_1(T) = \sum_{t=1}^{T} \left( \max_{i} \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_i^* - \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_{i_t}^* \right) = O(\sqrt{mT \log T})
\end{equation}

\textbf{Proof.} The proof proceeds in three steps.

\textit{Step 1: Confidence Ellipsoid Construction.}
By the self-normalized martingale inequality \cite{Abbasi2011Improved}, for any $\delta_{\text{conf}} > 0$, with probability at least $1 - \delta_{\text{conf}}/K$, for all $t \geq 1$:
\begin{equation}
\resizebox{0.92\columnwidth}{!}{$
\|\hat{\boldsymbol{\theta}}_{i,t} - \boldsymbol{\theta}_i^*\|_{\mathbf{A}_{i,t}} \leq \sigma_{\text{noise}}\sqrt{2\log\left(\frac{\det(\mathbf{A}_{i,t})^{1/2} \det(\lambda_{\text{reg}}\mathbf{I})^{-1/2}}{\delta_{\text{conf}}/K}\right)} + \sqrt{\lambda_{\text{reg}}}S
$}
\end{equation}
Using the determinant-trace inequality
\begin{equation}
\det(\mathbf{A}_{i,t}) \leq \left(\frac{\text{tr}(\mathbf{A}_{i,t})}{m}\right)^m \leq \left(\lambda_{\text{reg}} + \frac{tL^2}{m}\right)^m
\end{equation}
and applying a union bound over all $K$ detectors, with probability at least $1 - \delta_{\text{conf}}$, for all $i \in [K]$ and $t \geq 1$:
\begin{equation}
\|\hat{\boldsymbol{\theta}}_{i,t} - \boldsymbol{\theta}_i^*\|_{\mathbf{A}_{i,t}} \leq \alpha_{\text{ucb},t}
\end{equation}
where, for our choice of $\alpha_{\text{ucb}}$,
\begin{equation}
\resizebox{0.92\columnwidth}{!}{$
\alpha_{\text{ucb},t} = \sigma_{\text{noise}}\sqrt{m\log(1 + tL^2/\lambda_{\text{reg}}) + 2\log(K/\delta_{\text{conf}})} + \sqrt{\lambda_{\text{reg}}}S \leq \alpha_{\text{ucb}}.
$}
\end{equation}

\textit{Step 2: Instantaneous Regret Bound.}
Let $i^* = \arg\max_i \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_i^*$ be the optimal detector at time $t$. The UCB selection rule chooses:
\begin{equation}
i_t = \arg\max_i \left( \boldsymbol{\phi}_t^\top \hat{\boldsymbol{\theta}}_i + \alpha_{\text{ucb}} \|\boldsymbol{\phi}_t\|_{\mathbf{A}_i^{-1}} \right)
\end{equation}
Under the confidence event, we have:
\begin{align}
\boldsymbol{\phi}_t^\top \boldsymbol{\theta}_{i^*}^* &\leq \boldsymbol{\phi}_t^\top \hat{\boldsymbol{\theta}}_{i^*} + \alpha_{\text{ucb}} \|\boldsymbol{\phi}_t\|_{\mathbf{A}_{i^*}^{-1}} \\
&\leq \boldsymbol{\phi}_t^\top \hat{\boldsymbol{\theta}}_{i_t} + \alpha_{\text{ucb}} \|\boldsymbol{\phi}_t\|_{\mathbf{A}_{i_t}^{-1}} \\
&\leq \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_{i_t}^* + 2\alpha_{\text{ucb}} \|\boldsymbol{\phi}_t\|_{\mathbf{A}_{i_t}^{-1}}
\end{align}
where the first inequality uses the confidence bound, the second uses the UCB selection, and the third applies the confidence bound again. Thus, the instantaneous regret is:
\begin{equation}
r_t^{(1)} = \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_{i^*}^* - \boldsymbol{\phi}_t^\top \boldsymbol{\theta}_{i_t}^* \leq 2\alpha_{\text{ucb}} \|\boldsymbol{\phi}_t\|_{\mathbf{A}_{i_t}^{-1}}
\end{equation}

\textit{Step 3: Cumulative Regret via Elliptical Potential Lemma.}
By the elliptical potential lemma \cite{Dani2008Stochastic}:
\begin{equation}
\sum_{t=1}^T \|\boldsymbol{\phi}_t\|_{\mathbf{A}_{i_t,t-1}^{-1}}^2 \leq 2m\log\left(1 + \frac{TL^2}{\lambda_{\text{reg}} m}\right)
\end{equation}
Applying Cauchy-Schwarz:
\begin{align}
R_1(T) &= \sum_{t=1}^T r_t^{(1)} \leq 2\alpha_{\text{ucb}} \sum_{t=1}^T \|\boldsymbol{\phi}_t\|_{\mathbf{A}_{i_t}^{-1}} \\
&\leq 2\alpha_{\text{ucb}} \sqrt{T \sum_{t=1}^T \|\boldsymbol{\phi}_t\|_{\mathbf{A}_{i_t}^{-1}}^2} \\
&\leq 2\alpha_{\text{ucb}} \sqrt{2mT\log\left(1 + \frac{TL^2}{\lambda_{\text{reg}} m}\right)} \\
&= O(\sqrt{mT \log T})
\end{align}
This completes the proof. \hfill $\square$

\subsection{Proof of Theorem 2 (Level 2 Regret)}

\textbf{Theorem 2.} \textit{For Thompson Sampling on $C$ configurations per detector, with $N_i(T)$ selections of detector $i$, the cumulative regret satisfies:}
\begin{equation}
R_2(T) = \sum_{i=1}^{K} O(\sqrt{C \cdot N_i(T) \log N_i(T)})
\end{equation}

\textbf{Proof.} We analyze the hyperparameter selection problem for each detector separately.

\textit{Step 1: Reduction to Multi-Armed Bandit.}
Conditioned on detector $i$ being selected at times $\{t : i_t = i\}$, the hyperparameter selection problem reduces to a standard $C$-armed bandit over $N_i(T)$ rounds. The rewards $r_t \in [-1, 1]$ are normalized to $\tilde{r}_t = (r_t + 1)/2 \in [0, 1]$.

\textit{Step 2: Beta-Bernoulli Thompson Sampling Analysis.}
For bounded rewards in $[0,1]$, we model the normalized reward as a Bernoulli-like outcome and maintain Beta posterior distributions. By Theorem 1 of \cite{Agrawal2013Further}, for a $C$-armed bandit with bounded rewards, Thompson Sampling with Beta$(1,1)$ priors achieves expected regret:
\begin{equation}
\mathbb{E}[R_i(N_i)] \leq O\left(\sum_{c: \Delta_c > 0} \frac{\log N_i}{\Delta_c}\right)
\end{equation}
where $\Delta_c = \mu^* - \mu_c$ is the suboptimality gap for configuration $c$. This can be bounded as:
\begin{equation}
\mathbb{E}[R_i(N_i)] \leq O(\sqrt{C \cdot N_i(T) \log N_i(T)})
\end{equation}
using the gap-free bound from \cite{Agrawal2012Thompson}.

\textit{Step 3: Aggregation Across Detectors.}
Since the detector selections partition the time horizon (i.e., $\sum_{i=1}^K N_i(T) = T$), and each detector's hyperparameter selection is an independent bandit problem, the total Level 2 regret is:
\begin{equation}
R_2(T) = \sum_{i=1}^{K} R_i(N_i(T)) = \sum_{i=1}^{K} O(\sqrt{C \cdot N_i(T) \log N_i(T)})
\end{equation}
This completes the proof. \hfill $\square$

\subsection{Proof of Corollary (Combined Regret)}

\textbf{Corollary.} \textit{Let $(i^*, c^*)$ denote the optimal detector-configuration pair. The total regret decomposes as $R(T) = R_1(T) + R_2(T)$, where $R_1(T)$ captures suboptimality from detector selection and $R_2(T)$ from configuration selection. The combined bound is:}
\begin{equation}
R(T) = R_1(T) + R_2(T) = O(\sqrt{mT \log T} + \sqrt{CKT \log T})
\end{equation}

\textbf{Proof.} We combine the regret bounds from Theorems 1 and 2.

From Theorem 1, $R_1(T) = O(\sqrt{mT \log T})$.

For $R_2(T)$, we apply the Cauchy-Schwarz inequality:
\begin{align}
R_2(T) &= \sum_{i=1}^{K} O(\sqrt{C \cdot N_i(T) \log N_i(T)}) \\
&\leq O\left(\sqrt{C \log T} \sum_{i=1}^{K} \sqrt{N_i(T)}\right) \\
&\leq O\left(\sqrt{C \log T} \cdot \sqrt{K \sum_{i=1}^{K} N_i(T)}\right) \\
&= O\left(\sqrt{C \log T} \cdot \sqrt{KT}\right) \\
&= O(\sqrt{CKT \log T})
\end{align}
where we used $\log N_i(T) \leq \log T$, Cauchy-Schwarz ($\sum_i \sqrt{a_i} \leq \sqrt{K \sum_i a_i}$), and $\sum_i N_i(T) = T$.

Therefore:
\begin{equation}
R(T) = R_1(T) + R_2(T) = O(\sqrt{mT \log T} + \sqrt{CKT \log T})
\end{equation}

Since both terms grow as $O(\sqrt{T \log T})$, the average regret vanishes:
\begin{equation}
\lim_{T \to \infty} \frac{R(T)}{T} = \lim_{T \to \infty} O\left(\sqrt{\frac{\log T}{T}}\right) = 0
\end{equation}
This guarantees that AutoDD converges to the optimal detector-configuration pair as $T \to \infty$. \hfill $\square$

\subsection{Sample Complexity}

To achieve average regret at most $\epsilon$, we require $R(T)/T \leq \epsilon$. From the combined regret bound:
\begin{equation}
\resizebox{0.92\columnwidth}{!}{$
\frac{R(T)}{T} \leq \frac{c_1\sqrt{mT\log T} + c_2\sqrt{CKT\log T}}{T} = \frac{(c_1\sqrt{m} + c_2\sqrt{CK})\sqrt{\log T}}{\sqrt{T}}
$}
\end{equation}
for constants $c_1, c_2$. Setting this equal to $\epsilon$ and solving:
\begin{equation}
T = O\left(\frac{(m + CK)\log(K/\delta_{\text{conf}})}{\epsilon^2}\right)
\end{equation}
With $m = 15$ meta-features, $K = 7$ detectors, and $C = 5$ configurations, achieving $\epsilon = 0.01$ average regret requires approximately $T \approx 5 \times 10^5$ windows, which is reached early in typical streaming applications.
